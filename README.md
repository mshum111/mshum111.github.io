# Matthew Shum recreated website

This folder is a static website ready for GitHub Pages, Netlify, or Cloudflare Pages.

## Files
- `index.html` — homepage
- `res.html` — research page
- `papers/cvweb.html` — HTML placeholder/recreation of the CV page
- `ec105/ec105.html`, `stats/stats.html`, `gradio/ioclass.html` — course pages
- `style.css` — simple old-style academic website formatting

## Notes
The visible content was recreated from the publicly accessible Caltech mirror. Many PDF/resource links are placeholders (`#`) because the original binary files were not copied from the Caltech server in this environment. Replace those placeholders with uploaded PDFs or external links as needed.

## Publish on GitHub Pages
1. Create a repository named `mshum.github.io`.
2. Upload all files/folders from this directory.
3. Go to Settings > Pages and publish from the `main` branch.
